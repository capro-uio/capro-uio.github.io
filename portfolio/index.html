Open source we have built

Everything here is open source and free to use, whether or not you ever work with us. Most of it came out of a project that needed it, and we released it so the next group would not have to build the same thing again.

Showing all projects

Web apps

tachisto - jsPsych experiment builder (opens in a new tab)

Assemble a jsPsych experiment in the browser, then export readable jsPsych source and a self-contained HTML file you can host anywhere.

R-packages · Analyses

Lifebrain Global Brain Health Survey (opens in a new tab)

We conducted the data processing and analyses for all associated reports and publications, and released the data publicly.

R-packages

ggsegverse - Brain atlases in R (opens in a new tab)

Brain atlas data plotted in R — ggseg for 2D with ggplot2, ggseg3d for 3D with Three.js, and atlas packages covering a range of parcellations.

R-packages

tsdrtools - R packages inside TSD (opens in a new tab)

Install R packages inside TSD, UiO’s closed secure server, where install.packages() has no internet to reach.

R-packages

Nettskjemar (opens in a new tab)

Enables download of data and meta-data for surveys conducted with the Nettskjema survey tool by the University of Oslo.

Analyses · MRI

TSD Imaging processing pipeline

Custom MRI import and processing pipeline for the Center of Lifespan Changes in Brain and Cognition.

R-packages

ebrains.kg - EBRAINS Knowledge Graph in R (opens in a new tab)

Query the EBRAINS Knowledge Graph from R, so European neuroscience metadata can be pulled into an analysis instead of browsed by hand.

R-packages

nva - Nasjonalt Vitenarkiv in R (opens in a new tab)

Read Norway’s national research archive from R, for publication lists and reporting without manual exports.

R-packages · MRI

neuromat - Model matrices for neuroimaging (opens in a new tab)

Create the model matrices neuroimaging analyses need from a formula, rather than assembling the columns by hand.

Teaching

Project management in R - workshop (opens in a new tab)

Materials for a one-day workshop on managing a project in R: folder structure, version control, and making the analysis rerun.

Web apps

Data inspector for Nettskjema (opens in a new tab)

Make small corrections to incoming Nettskjema data without touching the originals, so a stray value can be fixed and the raw response still kept.

R-packages

uiothemes - UiO branding in R (opens in a new tab)

University of Oslo branding for R plots, documents and reports, so figures come out looking like UiO without anyone copying hex codes between projects.
